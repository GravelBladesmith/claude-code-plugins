**🧩 Claude Code Plugins** is the complete English-language guide to extending Claude Code with custom plugins. Learn how to build MCP servers, add slash commands, wire hooks, package a plugin, and share it with a team — with runnable TypeScript and a clean plugin architecture. Built for developers who want Claude Code to actually know their project, not just their prompt. **Completely free.** No signup. No paywall. No hidden chapters.
